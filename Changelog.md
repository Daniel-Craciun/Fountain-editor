Fountain editor change log

## [1.0.0] - 2025-12-13

This is the first release

### Keyframe editor / timeline

- Supports a pump track and a light track
- Arrow keys to navigate track (UP or DOWN arrow keys)
- Right click to create a keyframe
- Can specifiy if a keyframe transitions or not (T)
- Can create a keyframe on current track (K)
- Can create a keyframe on both tracks (CTRL + K)
- Can copy and paste selected keyframes (CTRL + C and CTRL + V)
- Can delete a keyframe (Backspace or Delete keys)

### Header

- Can load a project via a yaml file
- Can export the project into a yaml file
- Can copy the project data into the clipboard
- Button to move timeline to 0
- Button to move timeline to ending keyframe
- Button to move back 0.5s
- Button to move forward 0.5s
- Button to play/pause the show

### Nozzle editor

- Can control nozzle height
- Can control nozzle light
- Can control nozzle brightness
- Can copy and paste nozzle values (right click)
- Can select a group of nozzles (CTRL + left click)
- Can select all nozzles (A)
- Can modify nozzle name
- Can modify nozzle home assistant name
- Can modify nozzle calibration
